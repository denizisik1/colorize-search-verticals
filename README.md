#### Google Search Verticals

A Firefox addon that stops Google from reshuffling the search tabs.

Google reorders Images, Videos, Maps, News and the rest based on the query. Muscle memory breaks: the second tab is not always Images. This addon pins a stable order, puts omitted verticals back on the bar, and gives each tab its own muted color and pattern.

Listed on [addons.mozilla.org](https://addons.mozilla.org/addon/google-search-tab-colorizer/).

##### Local Install

1. Open `about:debugging` in Firefox
2. Choose **This Firefox**
3. Click **Load Temporary Add-on**
4. Select `manifest.json` in this repository
